# Tic Tac Toe Game

A simple web-based Tic Tac Toe game built with **HTML**, **CSS**, and **JavaScript**.  
This project demonstrates DOM manipulation, event handling, and game logic implementation in JavaScript.

---

## Features
- Interactive 3x3 Tic Tac Toe board.
- Two-player gameplay (X and O turns).
- Automatic detection of winning patterns.
- Display of winner message with option to start a new game.
- Reset functionality to clear the board and restart.

---

## Technologies Used
- **HTML5** for structure
- **CSS3** for styling
- **JavaScript (ES6+)** for game logic

## Usage
- Click on any box to place your mark (X or O).
- Players take turns automatically.
- When a winning combination is achieved, the winner message is displayed.
- Use the **New Game** button to start fresh.
- Use the **Reset** button to clear the board.
